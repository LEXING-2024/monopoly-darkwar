# 大富翁·暗战

> 中文回合制棋盘策略游戏 · 72 格环形地图 · 四季轮转 · 资源市场 · 七大自然灾害 · 强 AI 对手

在浏览器中运行，与 3~7 名 AI 对手争夺土地、资源与市场定价权。季节影响产出与物价，台风会在海上成长后登陆，聪明的对手会记住你的背叛——每一局都是不同的暗战。

## 特性

### 游戏机制

- **72 格环形棋盘**：圆角矩形商路，72 张圆牌沿路零叠压；森林（木材🌲）/ 高原（牛肉🐄）/ 沙漠（石油⛽）/ 沿海（鱼类🐟）4 大地形区，各含命运卡、机会卡、赌场、拍卖等特殊格
- **一眼可辨的图标**：四大地形各自色环、色带与深色墨线图案；特殊格独立配色；地产带玩家色外环与火漆印；资源、行动图标也有专属色牌
- **行动转盘**：转动转盘决定移动步数（0~12），卡片效果可增减步数
- **四季轮转**（春🌸 / 夏☀️ / 秋🍂 / 冬❄️）：
  - 价格修正：夏季鱼类 +50%、秋季牛肉/石油 +40%、春季木材 +10%、冬季牛肉 -30% 等
  - 产出修正、建造费用修正（春季 -20%）、起点奖励浮动（秋季 +500、冬季 -200）
  - 每季通过起点额外领取本季资源（6 单位）
- **资源经济**：4 种资源建采集建筑后基础产出 0.5 单位/地块/回合，市价每轮 ±4% 并向基准回归；**市场供给压力**——所有玩家集中抛售都会压低市价、惜售会推高价格
- **建筑系统**：购买地块、建造/升级采集建筑（设施建成后才有产出）、勘探增产、受损建筑地图上带 ⚠ 标记（自己的红色、他人的灰色），修复恢复产出；每格 1 个资源生产位 + 1 个通用位（商业/防灾/科技共用）
- **桥梁机制**：东西两桥横跨同一条河，过桥需付费；**仅冬季**桥头结薄冰，可绕行免费通过

### 七大自然灾害

| 灾害 | 机制 |
|------|------|
| 🌪️ 台风 | 自 0 级热带扰动生成，沿海湾密集航线连续移动并留下风暴尾迹；海上逐回合增强至 5 级，任意等级都可能登陆；登陆破坏 ±1~2 格（波及减半）；生命末期逐级减弱为热带低压后才消散 |
| 🏜️ 沙尘暴 | 沿路径连续横扫多格，波及无主地块 |
| ❄️ 雪灾 | 沿路径连续横扫多格，波及无主地块 |
| 🗻 地震 | 按强度破坏周边地块 |
| 🔥 火灾 | 局部蔓延破坏 |
| 🌊 洪水 | 沿河道淹没两岸地块 |
| 🏭 污染 | 石油泄漏笼罩地块，产出归零，并可能触发「环保抗议」事件链 |

游戏**前 10 回合为保护期**，不触发任何灾害与事件链。

### AI 对手（模块化大脑）

- **性格维度**：侵略性、风险偏好、合作倾向、囤积倾向、报复心、贪婪度——同难度内每局随机生成，个性各异
- **记忆与情绪**：被背叛 / 被举报会记仇，情绪影响后续决策
- **对手建模**：估算对手现金、资产、收入与威胁值，推断其垄断意图
- **策略状态机**：扩张 / 防守 / 攻击 / 垄断冲刺，随局势切换；季节预判提前建防灾建筑
- **四档难度**：简单 / 正常 / 困难 / 地狱（开局统一选择）

### 博弈交互

- **举报垄断**：对手垄断地形可发起举报，联合其他玩家共同制裁（AI 会权衡利弊决定是否加入）
- **主动交易**：与对手交换地块、资源、现金
- **拍卖竞价**：拍卖格竞拍无主地块
- **命运卡 / 机会卡**：随机事件，含收获暴跌、环保抗议等连锁事件链

### 移动端

- 单指平移（1:1 跟手：手指按住的地块跟到松手处）、双指围绕中点缩放
- 沉浸式全屏（隐藏状态栏与导航栏）
- 横竖屏自适应、输入法弹出不压缩页面、免滚动 UI 布局

## 操作说明

| 场景 | 操作 |
|------|------|
| 桌面 | 鼠标左键拖动平移、滚轮或双指缩放、点击地块查看详情 |
| 触屏 | 单指拖动平移、双指捏合缩放、点击地块查看详情 |
| 对局 | 转盘行动 → 落地结算 → 建造/升级/修复/交易 → 结束回合（手机端按钮在棋盘右下角） |

## 技术栈

| 层 | 技术 |
|----|------|
| UI | Vue 3 + Vite 6 |
| 游戏渲染 | Phaser 3（矢量绘制棋盘 / 地块 / 特效 / 棋子动画） |
| 音效 | WebAudio 实时合成（主增益/压缩/混响/限流，无音频文件，行动联动；顶栏可调主音量） |
| 测试 | tsx headless 模拟 + 平衡门禁 |

## 快速开始

### 环境要求

- Node.js ≥ 18

### 安装与开发

```bash
npm install

npm run dev        # 开发服务器 http://localhost:5173
npm run typecheck  # TypeScript 类型检查
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 本地预览生产构建
```

### 模拟与平衡门禁

游戏逻辑与渲染完全解耦（`src/core/` 为纯 TS），支持无 UI 批量模拟：

```bash
npm run sim 500     # headless 模拟 500 局（统计胜率、平均回合、破产人数等）
npm run sim:gate    # 四难度各 500 局：中位回合数低于地板即失败（防止改动把对局压得过短）
```

数值调参集中在 `src/core/config.ts` 的常量表中（季节、灾害概率、AI 难度、市场压力系数等），修改后请跑 `sim:gate` 回归。

│   │   │   ├── anticipate.ts    # 季节与灾害预判
│   │   │   ├── opponent.ts      # 对手建模与威胁评估
│   │   │   ├── memory.ts        # 记忆与情绪
│   │   │   ├── market.ts        # 市场操纵（抛售压价 / 囤积）
│   │   │   ├── act.ts           # 回合行动管线

上表只列入库内容。以下目录由工具生成或仅存在于本机，均已在 `.gitignore` 中排除：
